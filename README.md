## 📌 Overview

The **Currency Converter** is a simple and responsive web application that allows users to convert one currency into another using real-time exchange rates. The project demonstrates API integration with vanilla JavaScript and focuses on creating a clean, user-friendly interface without using any frontend frameworks.

---

# ✨ Features

* 🌍 Convert between multiple international currencies
* 💹 Fetches real-time exchange rates
* ⚡ Instant conversion results
* 🔄 Currency swap functionality
* 📱 Responsive design for desktop and mobile
* 🎨 Clean and intuitive user interface
* ❌ Handles invalid inputs gracefully

# 🌐 API Used

This project uses a public Currency Exchange API to retrieve live exchange rates.

The application:

* Sends a request to the API
* Receives exchange rate data in JSON format
* Calculates the converted amount
* Displays the result instantly
